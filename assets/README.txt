WordPress.org Plugin Directory Assets
=====================================

These files are uploaded separately to the WordPress.org SVN assets folder,
not included in the plugin ZIP.

Recommended files:
- banner-772x250.png
- banner-1544x500.png
- icon-128x128.png
- icon-256x256.png
- screenshot-1.png … screenshot-5.png (1280x720 or 4:3)

https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/
